# 🎂 Birthday 3D Website

A personal interactive birthday website created as a creative web development project.

The website uses **3D visuals, scrolling animations, transitions, and storytelling** to create a unique birthday experience rather than a traditional static birthday page.

✨ Features

* 🎨 Interactive 3D design
* 🖱️ Scroll-based animations
* 💫 Smooth transitions and effects
* ❤️ Personalized birthday message
* 📱 Responsive design
* 🌐 Built as a web development practice project

🎯 Purpose

This project was created as both a **personal birthday gift** and a way to practice my skills in modern web development, animations, UI/UX design, and interactive experiences.
